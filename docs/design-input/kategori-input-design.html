Informasi Kategori
Kategori digunakan untuk mengelompokkan menu seperti minuman, makanan, atau platters.
Nama kategori harus unik.
Slug otomatis dari nama kategori dan dapat diedit.
Semakin kecil angka, semakin awal kategori ditampilkan.
